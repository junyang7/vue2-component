Tag
====

主要用来展示一个标签，不应该具备按钮的属性
支持自定义样式


组件属性参数：
setting: {
    style: {
        default: {},
        hover: {},
    },
}

setting.style.default 拥有最高优先级，会原封不动的覆盖到 style 中

----

size
只会影响：padding/height/fontSize

枚举值：small/default/large
默认值：default


----

type

枚举值：b/bc/bbc
默认值：bc


纯边框：1种颜色
纯背景：1种颜色
边框背景：1中颜色，背景占0.5

自定义
